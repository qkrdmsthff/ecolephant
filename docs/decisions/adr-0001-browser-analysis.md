# 브라우저 분석과 서버 결과 저장 경계

상태: 설계 제안 · 날짜: 2026-10-17 · 근거: [사용자 제공 PDF 3~4쪽](../references/README.md).

## 맥락

원문은 영상을 브라우저 메모리에서만 처리하고 서버에는 각도·판정·시간을 저장하도록 제시합니다. AirPods는 로컬 도우미를 통해 입력하는 구조입니다.

## 제안

영상·관절점·보정·원시 모션 처리를 로컬에 두고 `ai/`를 브라우저 실행 가능한 순수 분석 경계로 둡니다. 백엔드는 소유권·파생 결과 검증·저장·집계를 담당합니다. 분석 모듈이 네트워크에 직접 접근하지 않습니다.

## 영향

카메라 프레임 업로드 API와 서버 영상 추론 endpoint를 정의하지 않습니다. frontend는 성능·탭 수명주기를 다뤄야 하며 도우미 연결 보안은 별도 검증이 필요합니다. `ai` 폴더가 별도 서버를 의미하지 않도록 역할을 명시합니다.

## 변경 조건

서버 추론·원본 저장이 필요해지면 사용자 동의·전송 계약·저장 정책·보안 검토를 포함하는 새 결정을 기록합니다. 이 초안만으로 원본 전송 범위를 확대하지 않습니다.
