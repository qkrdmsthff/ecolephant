# 사용자 여정과 지원 범위

## 측정 준비

사용자는 영상 처리 안내를 확인하고 카메라 권한 또는 도우미 연결을 허용합니다. 가능한 측정 방식을 고른 뒤 얼굴과 어깨를 가이드 안에 두고 기준 자세를 유지합니다. 필요한 센서의 안정 데이터가 확보된 경우에만 측정을 시작할 수 있습니다. 권한을 거부한 센서를 자동으로 다시 켜지 않습니다.

## 측정과 교정

센서별 값, 참고 종합값, 상태 이유, 측정 품질을 함께 확인합니다. 지속되는 주의 자세에만 설정한 채널로 알립니다. 센서 손실 시 이미 보정된 남은 센서가 있으면 모드를 전환하고 전환 구간을 기록합니다. 둘 다 없거나 보정이 없으면 판단 불가로 표시합니다.

사용자는 일시정지·재개·재보정·종료·알림 음소거를 수행할 수 있습니다. 일시정지와 재보정 시간에는 새 판정과 알림을 만들지 않습니다.

## 기록 확인

사용자는 오늘·이번 주·이번 달의 지표, 요일·시간대 흐름, 세션 목록·상세를 확인합니다. 측정 방식과 정책이 다른 기록은 그룹을 구분합니다. 기록을 삭제하면 관련 측정 창과 이벤트도 삭제됩니다.
