# 측정 정확도와 장치 호환성 검증 계획

이 계획은 실행 전입니다. 합성 fixture의 예상 판정 일치는 실제 각도 정확도·습관 개선 효과를 입증하지 않습니다.

## 단계

1. 웹캠 도 단위 매핑이 없는 상태에서는 특징·품질만 검증하고 각도 출력은 비활성으로 둡니다.
2. 별도 동의를 받은 실험에서 측면 기준 측정 또는 적절한 기준 장치와 동시 수집합니다. 고개 숙임과 머리 전방 이동을 분리하고 몸통 동반 숙임도 포함합니다.
3. 사람별·장치별로 학습/조정 데이터와 평가 데이터를 분리합니다. 같은 사람의 유사 프레임이 양쪽에 섞이지 않도록 합니다.
4. 전체 평균뿐 아니라 거리·조명·가림·안경·체형·화면 각도별 오차와 누락률을 기록합니다. 대상 수와 모집 기준은 팀이 사전 결정합니다.
5. 판정 구간별 혼동행렬, 정밀도·재현율, 각도 MAE·오차 분포, unknown 비율, 알림 오탐을 함께 보고합니다.
6. 허용 오차·누락·오탐 기준을 결과를 보기 전에 정하고 정책 프로필 승인 여부를 결정합니다.

## 호환성 시험표

| 항목 | 기록할 조건 | 확인 |
|---|---|---|
| 웹캠 | OS, 브라우저 버전, 해상도, fps, 조명, 거리, CPU | 인식·발열·지연·권한 해제 |
| AirPods | 모델, 펌웨어, macOS, 도우미 버전, 착용 방향 | API 지원·권한·축·부호·재연결 |
| 시간 정렬 | 두 시계 offset, 왕복 지연, drift, sleep/wake | 정렬 오차·역행·리셋 |
| 웹 보안 | 배포 origin, 인증서, 로컬 연결 방식, 브라우저 | 허용/거부 Origin·페어링 |
| 백그라운드 | 탭 비활성, 창 최소화, 절전, 잠금 | 수집 중단 검출·무효 집계·알림 |
| 기록 | 네트워크 끊김, 재시도, 새로고침, 강제 종료 | 중복·누락·미완료 상태 |

## 기록 양식

결과마다 날짜, commit, 정책 ID, 모델·도우미 버전, 실험 환경, 참가자 익명 식별자, 데이터 분할 방식, 기준 측정, 지표, 실패 사례와 한계를 남깁니다. 실험 원본은 일상 서비스 DB에 올리지 않습니다.

원문 논문의 수치를 이 구현의 목표 달성 결과로 옮겨 쓰지 않습니다. 근거 상태는 [근거 목록](../references/evidence-register.md)을 참고합니다.
