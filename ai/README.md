# 브라우저에서 실행하는 자세 분석 모듈

정규화된 관측값을 받아 보정, 품질 판단, 센서별 신호, 결합 판정, 지속 조건을 계산합니다. UI·네트워크와 분리하고 동일 입력·정책으로 동일 출력을 내도록 설계합니다. 웹캠 특징을 각도로 바꾸는 함수는 실측 전 확정하지 않습니다.

현재는 구현 준비 문서만 있습니다. 제품 구현 완료를 의미하지 않습니다.
