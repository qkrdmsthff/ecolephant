# 최초 문서와 계약 검사 기록

검사일은 2026-10-17입니다. Python 3.12.14, jsonschema 4.26.0, openapi-spec-validator 0.9.0 환경에서 PowerShell 진입점과 Python 검사기를 실행했습니다.

| 검사 | 결과 |
|---|---|
| 필수 파일과 원본 PDF SHA-256 | 통과 |
| Markdown 내부 경로와 제목·표 정렬 | 통과 |
| 요구사항 18개와 인수 계획 30개의 양방향 추적 | 통과 |
| HTTP 동작 12개의 고유 ID와 요구사항 연결 | 통과 |
| OpenAPI 3.1과 HTTP 스키마 22개 | 통과 |
| 로컬 도우미 JSON Schema | 통과 |
| 유효·무효 계약 사례 29개 | 기대한 수락·거부 결과와 일치 |
| 초안 정책의 출처·미승인 상태·전송 한도 | 통과 |

계약 사례에는 원본 필드 추가, 무효값을 0도로 표현, 센서 값 누락, 시간 창 겹침, 이벤트 순번 충돌, 통계 분모·비율 불일치, 완료 상태 누락, 도·rad 혼동, 시계 역행을 포함합니다.

제품 API 호출, 브라우저·도우미 실행, 실제 측정 정확도는 이 결과의 범위 밖입니다. [인수 시나리오](../../docs/quality/acceptance.md)는 모두 planned이며 [실측 계획](../../docs/quality/measurement-validation.md)에 따라 별도 검증합니다.

이 기록은 최초 패키지 상태에 대한 결과입니다. 이후 변경은 검사를 다시 실행하고 해당 작업 계획에 실행 결과를 남깁니다.
