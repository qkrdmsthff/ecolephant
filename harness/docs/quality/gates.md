# 변경 완료의 검사 범위

| 경계 | 완료 조건 |
|---|---|
| 문서 | 지도·상대 링크·짧은 문서·검토 정보·추적 연결 |
| 계약 | OpenAPI·Schema·정상/거부 fixture·시간·통계 불변식 |
| 구조 | 제품 폴더 의존·분석 모듈 I/O 경계. 실행 코드가 없으면 범위를 명시 |
| 보안 | 비밀정보와 원본 필드 차단. 실행 중 원본 미전송·소유권은 별도 확인 |
| 제품 | 적용 대상 AC와 실측·브라우저·장치 결과 |

자동 검사는 [진입점](../../scripts/README.md), 제품 검증은 [인수 계획](../../../docs/quality/acceptance.md)을 사용합니다. 결과마다 commit·정책·환경·범위를 남깁니다.
