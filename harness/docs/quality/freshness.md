# 문서 검토일과 드리프트 확인

[문서 목록](../../metadata/documents.json)은 경로·주제·상태·검토일을 기록합니다. 기본 검토 간격은 30일이며 실제 검토 없이 날짜를 일괄 새로 쓰지 않습니다.

[doc gardening](../../scripts/doc_gardening.py)은 검토일 누락·기간 초과와 계획 상태를 보고합니다. 초안이라는 이유만으로 문서를 실패 처리하지 않습니다. 잘못된 경로·날짜·등록 누락은 전체 검사에서 실패합니다.

문서와 코드의 의미가 어긋나는지는 작업자·리뷰가 확인합니다. 주기적 자동 실행은 별도로 요청·설정한 경우에만 추가합니다.
