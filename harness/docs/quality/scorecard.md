# 영역별 품질 상태

| 영역 | 현재 상태 | 다음 확인 |
|---|---|---|
| 제품·화면·판정 명세 | 초안 작성 | 미확정 결정 합의 |
| HTTP·도우미 계약 | 합성 검사 대상 | 실제 구현·장치 연동 |
| 하네스 지도·검사 | 문서·계약·검사기 검사 통과 | 변경마다 검사·검토일 관리 |
| frontend/backend/ai 실행 코드 | 미구현 | 단계별 구현과 회귀 검증 |
| 측정 정확도·제품 안전성 | 미검증 | 별도 실측·지원 환경 평가 |

미구현 영역에는 A 등급을 부여하지 않습니다. 실행 증거가 생기면 상태와 [기술 부채](../plans/tech-debt.md)를 함께 갱신합니다. 확인 기록은 [보고서](../../reports/harness-restructure.md)에 연결합니다.
