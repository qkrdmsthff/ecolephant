# 문서와 구현 검토 기준

| 경계 | 확인할 질문 |
|---|---|
| 범위 | REQ ID와 완료 조건이 연결되어 있는가? 초안과 승인 결과를 구분하는가? |
| 화면 | 권한·누락·무효·저장 실패를 구분하는가? 숫자와 판정 이유가 일치하는가? |
| 분석 | 기준·단위·시계·품질이 명시되어 있는가? 특징을 검증된 각도로 가장하지 않는가? |
| API | 스키마·예시·중복·배치 원자성·종료·오류·소유권이 같은 규칙인가? |
| 집계 | 분모0·무효 시간·혼합 모드·중복 알림·시간대를 올바르게 처리하는가? |
| 보안 | 영상·관절점·원시 IMU가 네트워크·로그에 나가지 않는가? 도우미 경계가 안전한가? |
| 검증 | 문서 검사·합성 알고리즘 검사·실측·브라우저·보안 검증 결과가 구분되는가? |

결함은 재현 조건, 실제 영향, 관련 경로·요구사항과 함께 제시합니다. 자동 검사 통과만으로 제품 완료나 정확도 검증을 승인하지 않습니다.
