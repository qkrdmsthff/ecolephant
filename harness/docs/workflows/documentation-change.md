# 작은 문서와 색인 관리

한 파일에는 한 주제를 두고 하네스 지식 문서는 80줄 이내로 유지합니다. 설명이 커지면 하위 파일과 짧은 색인으로 나눕니다.

- 새 문서는 해당 폴더의 index와 metadata/documents에 등록합니다.
- 경로 변경은 상대 링크·문자열 경로·manifest·추적표를 함께 바꿉니다.
- 검토 날짜는 실제 검토한 문서에만 갱신합니다.
- [문서 지도 생성](../../scripts/README.md) 후 전체 검사를 실행합니다.

원문·설계 제안·실측 결과는 [제품 문서 상태](../../../docs/index.md)로 구분합니다.
