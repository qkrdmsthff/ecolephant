# 설계의 공통 원칙

1. 장치·네트워크·설정 경계에서 값을 파싱하고 단위·범위·누락을 확인합니다.
2. 센서 원본과 서버 저장 결과의 허용 범위를 분리합니다.
3. 인식 실패·일시정지·재보정을 정상으로 채우지 않습니다.
4. UI 표시값과 센서 조합 판정의 의미를 함께 설명합니다.
5. 같은 입력·보정·정책이 같은 분석 출력을 내게 합니다.
6. 수치 변경은 새 정책 버전과 검증 근거로 추적합니다.
7. 반복해서 어기는 규칙은 [독립 검사](../../scripts/README.md)로 옮깁니다.

실제 센서 규칙은 [판정 명세](../../../docs/measurement/decision-rules.md), 처리 경계는 [아키텍처](../../../ARCHITECTURE.md)를 따릅니다.
