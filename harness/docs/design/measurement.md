# 분석 변경의 설계 확인

입력 정규화, 시간 정렬, 보정, 품질, 각도 추정, 조합 판정, 알림 후보 순서를 확인합니다. 변환 중간값을 검증된 도 단위로 표현하지 않습니다.

- 새 특징은 단위·좌표·품질·기준값 수명을 적습니다.
- 기존 입력과 호환되지 않으면 새 정책 ID를 만듭니다.
- 웹캠 매핑 실측 전 각도 출력을 완료 처리하지 않습니다.
- 모드·보정 전환에서 버퍼와 지속 시간 초기화를 확인합니다.

정식 순서는 [신호 파이프라인](../../../docs/measurement/signal-pipeline.md)과 [실측 계획](../../../docs/quality/measurement-validation.md)에 있습니다.
