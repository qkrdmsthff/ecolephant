# 화면 변경의 설계 확인

화면은 장치 상태, 분석 품질, 저장 상태를 각각 표현합니다. 서버 저장 실패가 사용자의 자세 판정으로 보이지 않게 합니다.

- 원시 관측을 그리는 코드와 판정 코드를 분리합니다.
- 숫자·문구·아이콘을 함께 쓰고 키보드 초점을 유지합니다.
- 대기·무효·권한 거부·부분 센서 모드의 상태를 설계합니다.
- 실제 구현 전 [화면](../../../docs/ui/screens.md)과 [상태 전이](../../../docs/ui/state-machine.md)를 연결합니다.

브라우저 권한·알림·백그라운드 동작의 실제 지원 범위는 실측 결과로 정합니다.
