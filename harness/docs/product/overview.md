# 제품 작업의 기준 문서

이 하네스가 다루는 제품은 노트북 자세 측정 웹 MVP입니다. 작업 시작 시 다음 순서로 범위를 확인합니다.

1. [PRD](../../../PRD.md)의 출시 대상 모드와 완료 기준.
2. [요구사항](../../../docs/product/requirements.md)의 REQ ID.
3. [미확정 결정](../../../docs/decisions/open-decisions.md)의 적용 상태.

의자 센서·진동·졸음 분석은 이 제품 범위에 추가된 요구가 아닙니다. 새로운 요구가 들어오면 PRD와 추적표에서 범위를 먼저 갱신합니다.
