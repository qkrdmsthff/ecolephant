# 카메라 미리보기 연결

- 상태: completed
- 생성일: 2026-10-17
- 관련: REQ-001, REQ-003, REQ-004.
- 범위: 사용자 요청에 따라 실제 카메라 화면을 표시하고 모델 연결은 보류.

## 산출물

웹캠 훅·실시간 미리보기·권한 오류·장치 및 페이지 수명주기 정리·모델 연결 자리.
기본 준비 화면의 가상 기준 설정과 데모 시작을 제거하고 측정 시작은 비활성화했습니다.
현재 카메라 경로는 영상 분석·알림·세션 생성·저장을 실행하지 않습니다.

## 확인 경계

빌드·린트·문서 정적 검사 결과는 [현황](../../../../docs/development/mvp-status.md)에 기록합니다.
실제 사용자 장치 테스트를 실행한 것은 아닙니다.
[범위 결정](../../../../docs/decisions/adr-0003-camera-preview-scope.md)을 따릅니다.
