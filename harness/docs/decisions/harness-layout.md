# 하네스 세분화 구조 결정

상태: 적용 · 날짜: 2026-10-17 · 근거: 사용자의 다수 폴더·작은 문서 요청.

하네스의 지식을 product/design/architecture/roles/workflows/quality/reliability/security/plans/decisions/templates/references로 나눕니다. 상위 파일은 색인과 경로를 안내하고 본문은 한 주제씩 작성합니다.

정책·HTTP·도우미·인수 fixture를 별도 폴더에 두고 검사기도 책임별 모듈로 나눕니다. 제품 명세는 루트 docs의 해당 기준 문서로 연결합니다.

역할 문서는 순차 점검에도 사용할 수 있습니다. 별도 에이전트 실행 권한이나 배포·푸시 권한을 새로 부여하지 않습니다. 자세한 참고 범위는 [참고 기록](../references/harness-pattern.md)에 있습니다.
