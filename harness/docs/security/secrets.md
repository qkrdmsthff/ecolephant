# 비밀정보 검사와 대응

키·인증 토큰·개인 키를 커밋하지 않습니다. 실제 환경 파일은 ignore 규칙으로 보호하고 예시는 작동하지 않는 합성 값으로 만듭니다.

[비밀정보 검사](../../scripts/checks/secrets.py)는 추적 파일과 ignore되지 않은 새 텍스트 파일을 대상으로 강한 패턴을 확인합니다. 발견 시 내용은 출력하지 않고 파일·줄 위치만 알립니다.

패턴 검사는 모든 비밀을 찾는 도구가 아닙니다. 커밋 전 실제 차이와 로그를 함께 확인합니다. 노출된 자격은 삭제만으로 복구되지 않으므로 해당 자격의 폐기·교체도 처리합니다.
