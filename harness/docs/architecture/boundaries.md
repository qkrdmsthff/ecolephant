# 입력 경계와 Provider 책임

장치 어댑터는 원본을 정규화된 관측으로 바꾸고, 분석 모듈은 해석·판정을 담당합니다. 시계·인증·통신·저장은 명시적 인터페이스로 주입합니다.

- 카메라: 좌표·크기·confidence·단조 시각을 확인합니다.
- 도우미: 인증·protocol·stream·seq·축·단위를 확인합니다.
- HTTP: 허용 필드·소유자·정책·중복·상태를 확인합니다.
- 집계: 승인된 창·이벤트·정책으로 다시 계산합니다.

[제품 아키텍처](../../../ARCHITECTURE.md)와 [데이터 모델](../../../docs/data/model.md)이 세부 기준입니다. 참조 저장소의 범용 계층 이름은 현재 제품에 맞는 경계로 적용했습니다.
