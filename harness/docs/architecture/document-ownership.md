# 문서의 기준 위치

| 내용 | 기준 위치 |
|---|---|
| 제품 범위 | 루트 PRD |
| 제품 처리 경계 | 루트 ARCHITECTURE |
| 화면·판정·집계·보안 | 루트 docs의 해당 주제 |
| HTTP·도우미 필드 | OpenAPI·JSON Schema |
| 작업 절차·역할·품질 | harness/docs |
| 파일·문서·요구사항 연결 | harness/metadata |
| 합성 검증 입력 | harness/fixtures |

동일 규칙을 여러 문서에 복사하지 않고 기준 문서로 연결합니다. 기준이 바뀌면 연결된 계약·fixture·시나리오를 확인합니다. [문서 색인](../../../docs/index.md)에서 정식 명세를 찾습니다.
