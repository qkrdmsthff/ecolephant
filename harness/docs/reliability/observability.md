# 개인정보를 제외한 관측 정보

오류 분석에는 request_id, 세션 식별자, 정책·앱·도우미 버전, 모드 변경, 품질 상태, 배치 수신 순번, 제한된 오류 코드를 사용합니다.

영상·랜드마크·원시 IMU·토큰·본문 전체 덤프를 로그에 넣지 않습니다. 세션 ID도 공개 로그와 지원 문의에서 필요한 범위로 취급합니다.

처리 지연·unknown 비율·큐 길이·재시도·알림 전달 결과는 제품 성능 기준을 정한 뒤 계측합니다. 목표 수치는 실측 전 임의의 달성 결과로 쓰지 않습니다. [개인정보 원칙](../../../docs/security/privacy-and-security.md)을 따릅니다.
