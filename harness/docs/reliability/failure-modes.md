# 중단과 누락의 실패 모드

| 실패 | 결과와 처리 |
|---|---|
| 필수 관절점 누락 | 해당 센서 무효, 0도·정상으로 대체하지 않음 |
| AirPods 중단 | 보정된 남은 센서로 전환하거나 unknown |
| 회전·stale·시계 역행 | 잘못된 조합을 막고 창·버퍼 재설정 |
| 재보정 실패 | 이전 기준 적용 중지 상태 유지 |
| 저장 지연·중복 | 파생 결과 큐·동일 ID 재시도·중복 응답 |
| 종료 전 누락 | final_seq와 final_event_seq가 해소될 때까지 완료 보류 |
| 탭 종료·절전 | 잃은 구간 unknown, 미완료 세션 구분 |

상태 전이는 [제품 상태 명세](../../../docs/ui/state-machine.md), 복구 확인은 [복구 기준](recovery.md)을 따릅니다.
